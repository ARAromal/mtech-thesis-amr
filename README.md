# Deep Learning for Beta-Lactamase Classification & AMR Prediction

This web application leverages a deep learning model to classify beta-lactamase antibiotic classes and predict anti-microbial resistance (AMR) patterns from protein sequences. This project is part of my M.Tech Thesis in Bioinformatics.

## 🚀 Features
* **Sequence-Based Prediction**: Input genetic sequences to identify AMR gene classes.
* **FASTA Support**: Handles standard FASTA formats.
* **Deep Learning Backend**: Powered by a CNN-based architecture trained on curated resistome data.

## 🛠️ Tech Stack
* **Language**: Python
* **ML Framework**: TensorFlow / Keras
* **Bioinformatics**: Biopython
* **Deployment**: Streamlit
